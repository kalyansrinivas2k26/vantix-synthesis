
# Decision Rights

| Decision | Authority |
|---|---|
| Source fact / status / severity | originating project |
| Source approval / closure state | originating project |
| Source Six Sigma denominator | originating project |
| Source evidence validity | originating project plus Synthesis contract/provenance gate |
| Correlation class | deterministic Synthesis engine |
| Correlation explanation | bounded AI after deterministic classification |
| AI-output validity | deterministic Synthesis validator |
| Executive route | deterministic Synthesis policy |
| Consequential executive disposition | human decision |
| Production action | outside current Portfolio Preview |

## Non-delegation rule

AI is not a source-of-record and not an approval authority.
