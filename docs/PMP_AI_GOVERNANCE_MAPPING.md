
# PMP / PMI AI Governance Mapping

This is a portfolio governance mapping, not PMI endorsement.

| Governance theme | Synthesis implementation |
|---|---|
| Value / benefits | cross-domain executive correlation without source-authority loss |
| Governance | versioned source contracts and deterministic correlation policy |
| Stakeholder accountability | source owners, Synthesis engine and human approver have separate rights |
| Risk | contradiction, compounding, provenance and degraded-source risks are explicit |
| Human oversight | consequential disposition remains human |
| Decision authority | AI explains; deterministic logic classifies/routes |
| Transparency | every correlation retains source records, projects and evidence refs |
| Responsible AI | bounded prompts, critique, deterministic validation and fail-closed tests |
| Change control | source schema and manifest versions are explicit |
