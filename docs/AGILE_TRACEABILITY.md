
# Agile Traceability

## Product increment

The v0.1 increment proves:
- four-source normalized contract;
- six correlation classes;
- deterministic correlation routing;
- bounded AI explanation/critique;
- human-decision boundary;
- evidence/audit output;
- adversarial suite;
- CI/repository controls.

## Definition of Ready

A source signal is ready for Synthesis only when:
- source project/domain are known;
- source record ID is present;
- schema version is supported;
- entity/outcome keys exist;
- evidence references and provenance are present;
- authoritative fields are declared.

## Definition of Done

A correlation is done only when:
- deterministic class exists;
- source bindings are retained;
- evidence refs resolve;
- source authority remains unchanged;
- AI explanation passes validation;
- human-decision requirements are satisfied for consequential routes;
- audit evidence is written.

AI does not become Product Owner, Scrum Master or sprint-commitment authority.
