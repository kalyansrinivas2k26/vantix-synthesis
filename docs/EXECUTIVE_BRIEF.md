
# Executive Brief

**Business outcome:** VANTIX Synthesis turns separate governance, delivery and customer-outcome signals into evidence-backed executive correlations without surrendering source authority to AI.

## Situation

Enterprise operating issues are distributed across governance, delivery, commitment and customer-outcome systems.

## Complication

No fresh external competitive research was performed for this Synthesis build. The project therefore makes no claim that commercial observability, Customer Success, process-mining or AI-governance platforms cannot correlate cross-domain signals. Its demonstrated differentiation is limited to the evidence-governed composition implemented in this repository.

## Question

How can separate source systems be correlated into an executive view without creating unsupported relationships, flattening domain measurements, or allowing AI to overwrite authoritative source facts?

## Answer

Normalize only the minimum shared fields, preserve source authority, require provenance and evidence, classify correlations deterministically into six explicit classes, use AI only to explain validated relationships, validate AI output, and retain human authority for consequential executive disposition.

## Evidence

- two sanitized n8n workflow exports;
- exact-node offline execution of the main correlation chain;
- six correlation classes generated from the synthetic reference fixture;
- 24/24 adversarial cases executed offline against the shipped adversarial workflow code;
- workflow/evidence SHA binding;
- graph-invariant checks;
- package negative tests;
- explicit source manifest and schema contracts.

## What This Doesn't Prove Yet

The project does not prove live cross-repository integration, live Salesforce ingestion, live model-provider execution, production identity, production-scale correlation precision/recall, customer impact, stable process capability, or production readiness.

## Roadmap

1. Bind final Projects 1–4 GitHub commit SHAs after their live CI checks.
2. Upload Synthesis and require its own GitHub Actions Green.
3. Record the 60–90 second portfolio demo.
4. Add live source adapters only if the portfolio is intentionally advanced beyond Portfolio Preview.
