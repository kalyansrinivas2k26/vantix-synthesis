
# Independent Synthesis Critique Prompt

Review the bounded explanation against the deterministic correlation record.

Set:
- `unsupportedClaimFlag`
- `inventedEvidenceFlag`
- `sourceAuthorityOverrideFlag`
- `routeOverrideFlag`
- `critiqueNotes`

Fail the explanation if it:
- changes the deterministic correlation class or route;
- alters source severity/status/claim values;
- references unknown evidence;
- suppresses a contradiction;
- converts synthetic evidence into production evidence;
- creates a pooled enterprise DPMO/Sigma/Cpk claim.

The critique itself is advisory. Deterministic validation owns whether the narrative may advance.
