
# Contributing

Changes must preserve:
- source authority;
- provenance;
- deterministic correlation classification;
- the six-class taxonomy;
- no universal risk score;
- no pooled domain DPMO denominator;
- bounded AI;
- human authority;
- synthetic/production evidence labels.

For every material change:
1. update tests;
2. run repository validation;
3. run graph validation;
4. run exact-node tests;
5. regenerate checksums;
6. update evidence/index/changelog where applicable.
