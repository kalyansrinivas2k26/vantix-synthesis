
# Security Policy

This repository is a sanitized Portfolio Preview.

Do not commit:
- API keys;
- OAuth secrets;
- access tokens;
- production customer data;
- private Salesforce org identifiers;
- authenticated user/session material.

AI output is not authoritative for:
- source facts;
- source severity/status;
- source approval/closure state;
- correlation classification;
- executive routing;
- human approval.

See `docs/OWASP_AI_SECURITY_MAPPING.md`.
